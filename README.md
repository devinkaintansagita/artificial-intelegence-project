# artificial-intelegence-project
A C++ console-based expert system designed to diagnose the level of online game addiction using the Certainty Factor (CF) method. The system processes user responses based on predefined symptoms and expert knowledge to determine the level of online game addiction.

# Project Overview
Online gaming is a popular form of entertainment. However, excessive gaming may affect daily activities, responsibilities, and social interactions. This project implements an Expert System to help identify the potential level of online game addiction based on several behavioral indicators. The Certainty Factor method is used to represent the degree of certainty in the diagnostic process. The system processes the user's answers and calculates the certainty value to determine the corresponding diagnosis.

# Objectives
The objectives of this project are:
- To develop an expert system for diagnosing online game addiction.
- To implement the Certainty Factor method.
- To apply C++ as the programming language.
- To implement expert-system logic in a console application.
- To process user responses based on predefined symptoms and rules.
- To provide a simple diagnostic result through the console.

# Expert System
An Expert System is an artificial intelligence application that uses knowledge and rules to solve problems in a specific domain. In this project, the expert system uses knowledge related to online game addiction. The system collects information from the user through a series of questions and processes the answers using predefined rules and Certainty Factor values.
The general process is: User Input -> Symptoms / Evidence -> Expert Rules -> Certainty Factor Calculation -> Diagnosis

# Certainty Factor Method
The Certainty Factor (CF) method is used in expert systems to represent the level of confidence in a hypothesis based on available evidence. The resulting CF value is used by the system to determine the diagnosis according to the rules implemented in the program.

# How to Run
Steps
1. Open Code::Blocks.
2. Open the C++ project or source file.
3. Make sure the C++ compiler is properly configured.
4. Build the project using Build → Build.
5. Run the program using Build → Run or press F9.
6. Follow the instructions displayed in the console.
7. Answer the diagnostic questions.
8. The system will process the answers using the Certainty Factor method.
9. The diagnostic result will be displayed in the console.
